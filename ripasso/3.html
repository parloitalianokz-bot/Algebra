📚 Теоретические основы

Для решения уравнений из этого раздела мы будем использовать следующие алгебраические свойства:

  • Раскрытие скобок: Используем формулы квадрата суммы (a ± b)² = a² ± 2ab + b² и правила умножения многочленов (фонтанчиком).
  • Приведение подобных слагаемых: Переносим все члены с неизвестным x в левую часть, а числа — в правую, меняя знак при переносе через знак равенства.
  • Разность квадратов: a² - b² = (a - b)(a + b). Если уравнение имеет вид A² - B² = 0, оно раскладывается как (A - B)(A + B) = 0, что даёт два простых уравнения.

💡 Пример с решением (22.4)

Задание: Решите уравнение:

-3(x³ - 5x - 7) - 2x + 8,2 - 3(2,3 - x³ - 5x) = 0
Шаг 1: Раскрываем скобки Умножаем каждое слагаемое в скобках на множитель перед ними, внимательно следим за знаками:
-3x³ + 15x + 21 - 2x + 8,2 - 6,9 + 3x³ + 15x = 0
Шаг 2: Приводим подобные слагаемые Группируем члены с x³, с x и свободные числа:
(-3x³ + 3x³) + (15x - 2x + 15x) + (21 + 8,2 - 6,9) = 0
Шаг 3: Выполняем вычисления
0x³ + 28x + 22,3 = 0
28x = -22,3
Шаг 4: Находим x Делим обе части на 28:
x = -22,3 / 28
x = -223 / 280
Ответ: x = -223/280 (или примерно -0.796)

✍️ Практика (реши самостоятельно)

Задание 22.2
-(x² - 2) - 0,3x + 7x + (x² - 0,2x) = 0
Подсказка: Раскройте скобки. Обратите внимание на знак минуса перед первой скобкой — он меняет знаки всех слагаемых внутри! Квадраты x² взаимно уничтожатся. Соберите все числа с x слева, а числа без x перенесите вправо.
Задание 23.3
3(2x - 5)² - 4(3 - 2x)² + 4x² = 0
Подсказка: Вам понадобится формула квадрата разности: (a - b)² = a² - 2ab + b². Примените её к обеим скобкам в квадрате. Затем раскройте внешние скобки, умножив результаты на 3 и на -4. Будьте предельно внимательны со знаками при умножении на отрицательное число!
Задание 24.1
2² + 3x = 0,25
Подсказка: Вычислите 2² (это 4). Перенесите это число в правую часть уравнения с противоположным знаком. Обратите внимание на десятичную дробь.
Задание 24.2
3x + 3²x = 9² + x
Подсказка: Сначала вычислите степени: 3² = 9 и 9² = 81. Затем соберите все члены с x в левой части (не забудьте поменять знак у +x при переносе). Число 81 оставьте справа, а члены без x из левой части перенесите вправо.
