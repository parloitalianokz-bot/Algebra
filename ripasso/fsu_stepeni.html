⚡ Свойства степеней

Степень — это удобный способ записать умножение одинаковых множителей. Например, \( a^4 = a \cdot a \cdot a \cdot a \).

Запомни: Основание — это число, которое умножается. Показатель — сколько раз оно умножается само на себя.

Основные свойства

am · an = am+n
Пример: 23 · 24 = 27 = 128
am / an = am−n (a ≠ 0)
Пример: 56 / 52 = 54 = 625
(am)n = am·n
Пример: (32)3 = 36 = 729
(a · b)n = an · bn
Пример: (2 · 5)3 = 23 · 53 = 8 · 125 = 1000
(a / b)n = an / bn (b ≠ 0)
Пример: (6 / 2)4 = 64 / 24 = 1296 / 16 = 81
a0 = 1 (a ≠ 0)
Пример: 170 = 1, (−5)0 = 1
a−n = 1 / an (a ≠ 0)
Пример: 2−3 = 1 / 23 = 1/8
Важно! Отрицательное основание в чётной степени даёт положительный результат, в нечётной — отрицательный. Например: (−2)4 = 16, (−2)3 = −8.

✖️ Формулы сокращённого умножения (ФСУ)

Эти формулы позволяют быстро раскрывать скобки и упрощать выражения. Их обязательно нужно выучить наизусть!

Квадрат суммы и разности

(a + b)2 = a2 + 2ab + b2
Пример: (x + 3)2 = x2 + 6x + 9
(a − b)2 = a2 − 2ab + b2
Пример: (y − 5)2 = y2 − 10y + 25

Разность квадратов

(a + b)(a − b) = a2 − b2
Пример: (7 + x)(7 − x) = 49 − x2

Куб суммы и разности

(a + b)3 = a3 + 3a2b + 3ab2 + b3
Пример: (m + 2)3 = m3 + 6m2 + 12m + 8
(a − b)3 = a3 − 3a2b + 3ab2 − b3
Пример: (k − 1)3 = k3 − 3k2 + 3k − 1

Сумма и разность кубов

a3 + b3 = (a + b)(a2 − ab + b2)
Пример: 8 + 27 = 23 + 33 = (2+3)(4 − 6 + 9) = 5 · 7 = 35
a3 − b3 = (a − b)(a2 + ab + b2)
Пример: 64 − 8 = 43 − 23 = (4−2)(16 + 8 + 4) = 2 · 28 = 56
Как запомнить:
• Квадрат суммы/разности: «квадрат первого +/− два произведения + квадрат второго»
• Разность квадратов: «сумма на разность»
• Кубы: знак в середине такой же, как в скобке (для суммы кубов) или противоположный (для разности).
