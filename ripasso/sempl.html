📚 Основные формулы и правила

Привет, Камилла! Для успешного выполнения заданий по упрощению выражений тебе понадобятся следующие формулы сокращенного умножения и правила:

1. Квадрат суммы:
(a + b)² = a² + 2ab + b²
2. Квадрат разности:
(a - b)² = a² - 2ab + b²
3. Умножение многочленов:
(x - a)(x + b) = x² + bx - ax - ab

Важные правила:

  • Всегда раскрывай скобки в первую очередь, используя формулы или фонтанчик (распределительное свойство).
  • Будь очень аккуратна со знаками «минус» перед скобками: они меняют все знаки внутри скобки на противоположные!
  • В конце приведи подобные слагаемые (складывай или вычитай коэффициенты при одинаковых степенях буквы a).

✏️ Задание 9. Упростите выражения

Пример 9.1 (Пошаговое решение)

(a + 7)² + (a - 2)(a + 5) - 7a

Шаг 1: Раскрываем квадрат суммы для первой части
Применяем формулу (a + 7)² = a² + 14a + 49.
Выражение принимает вид: a² + 14a + 49 + (a - 2)(a + 5) - 7a
Шаг 2: Умножаем две скобки друг на друга
(a - 2)(a + 5) = a² + 5a - 2a - 10 = a² + 3a - 10.
Теперь подставляем это в общее выражение: a² + 14a + 49 + a² + 3a - 10 - 7a
Шаг 3: Приводим подобные слагаемые
  • Члены с a²: a² + a² = 2a²
  • Члены с a: 14a + 3a - 7a = 10a
  • Числа (свободные члены): 49 - 10 = 39
Итоговый ответ для 9.1: 2a² + 10a + 39

🎯 Задание 9.4 (Твоя очередь!)

Попробуй решить сама, используя образец выше:

8 - (a + 5)² - (a - 4)(a + 7) + 16a

Подсказка: Не забудь, что минус перед первой скобкой -(a + 5)² поменяет знак каждого слагаемого внутри после возведения в квадрат!

✏️ Задание 10. Упростите выражения

Пример 10.1 (Пошаговое решение)

4(a - 1)² + (a - 2)(6 - a) - 13

Шаг 1: Возводим в квадрат и умножаем на коэффициент 4
Сначала (a - 1)² = a² - 2a + 1.
Умножаем на 4: 4(a² - 2a + 1) = 4a² - 8a + 4.
Шаг 2: Умножаем вторую пару скобок
(a - 2)(6 - a) = 6a - a² - 12 + 2a = -a² + 8a - 12.
Шаг 3: Складываем всё вместе и приводим подобные
4a² - 8a + 4 - a² + 8a - 12 - 13
  • Члены с a²: 4a² - a² = 3a²
  • Члены с a: -8a + 8a = 0 (они взаимно уничтожаются!)
  • Числа: 4 - 12 - 13 = -21
Итоговый ответ для 10.1: 3a² - 21

Подсказка: Будь внимательна с первым минусом перед квадратом и аккуратно перемножь многочлены во второй скобке.

✏️ Задание 11. Упростите выражения

Пример 11.1 (Пошаговое решение)

7(2a + 1)² - (3a - 2)(6 - 2a) - 3a²

Шаг 1: Возводим в квадрат выражение с коэффициентом
(2a + 1)² = (2a)² + 2·(2a)·1 + 1² = 4a² + 4a + 1.
Умножаем на 7: 7(4a² + 4a + 1) = 28a² + 28a + 7
Шаг 2: Раскрываем скобки умножения со знаком минус перед ними
(3a - 2)(6 - 2a) = 18a - 6a² - 12 + 4a = -6a² + 22a - 12.
Учитываем минус перед ними: -(-6a² + 22a - 12) = 6a² - 22a + 12
Шаг 3: Собираем всё в единую строку и упрощаем
28a² + 28a + 7 + 6a² - 22a + 12 - 3a²
  • Члены с a²: 28a² + 6a² - 3a² = 31a²
  • Члены с a: 28a - 22a = 6a
  • Числа: 7 + 12 = 19
Итоговый ответ для 11.1: 31a² + 6a + 19
